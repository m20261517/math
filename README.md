# math

## 초등학교 6학년 수학 6단원 수업 모델

Teachable Machine을 활용하여 웹캠으로 입체도형을 인식하고, **원기둥·원뿔·구**를 구별하는 학습용 웹 앱입니다.

### 주요 기능

- 웹캠 영상 실시간 표시
- 원기둥, 원뿔, 구 이미지 분류
- 현재 인식된 도형과 각 도형별 확률(%) 표시
- 스마트폰에서도 사용할 수 있는 반응형 디자인
- 카메라 영상 좌우 반전 없이 표시

### 사용 방법

1. 웹 앱을 HTTPS 환경 또는 `localhost`에서 실행합니다.
2. **카메라 시작** 버튼을 누릅니다.
3. 카메라에 원기둥, 원뿔 또는 구를 비춥니다.
4. 화면에 표시되는 인식 결과와 확률을 확인합니다.

### 모델

Teachable Machine 이미지 분류 모델을 사용합니다.

- 모델 URL: https://teachablemachine.withgoogle.com/models/q3uuf66Pv/

### 수업 활용

학생들이 주변의 입체도형을 직접 카메라에 비춰 보며 원기둥, 원뿔, 구의 모양을 관찰하고 서로 비교할 수 있도록 만든 초등학교 6학년 수학 6단원 수업 보조 자료입니다.
