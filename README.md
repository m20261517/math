# math

## 초등학교 6학년 수학 6단원 수업 모델

Teachable Machine을 활용하여 입체도형 사진이나 웹캠 영상을 분석하고, **원기둥·원뿔·구**를 구별하는 학습용 웹 앱입니다.

### 배포 링크

[원기둥·원뿔·구 구별하기 앱 실행하기](https://m20261517.github.io/math/?v=80cf1413)

> GitHub Pages가 활성화되어 있어야 위 링크에서 앱을 실행할 수 있습니다.

[교사용 평가 화면] (https://m20261517.github.io/math/eval.html)
### 주요 기능

- 웹캠 영상 실시간 표시 및 분류
- 기기에서 선택한 사진 업로드 및 분류
- 원기둥, 원뿔, 구 이미지 분류
- 현재 인식된 도형과 각 도형별 확률(%) 표시
- 최고 확률이 70%(0.7) 미만이면 **잘 모르겠어요**로 안내
- 스마트폰에서도 사용할 수 있는 반응형 디자인
- 카메라 좌우 반전 기능
- 사진과 카메라 영상은 브라우저 안에서만 처리되며 외부로 전송하지 않음

### 사용 방법

1. 웹 앱을 HTTPS 환경 또는 `localhost`에서 실행합니다.
2. **카메라 시작** 버튼을 누르고 카메라 권한을 허용하거나, **사진 올리기** 버튼으로 기기에 있는 이미지를 선택합니다.
3. 카메라에는 원기둥, 원뿔 또는 구를 비추고, 사진은 도형이 잘 보이는 이미지를 선택합니다.
4. 화면에 표시되는 인식 결과와 각 도형의 확률을 확인합니다.
5. 최고 확률이 70% 미만이면 특정 도형으로 확정하지 않고 **잘 모르겠어요**라고 표시합니다.
6. 사진을 다시 분석하려면 **사진 올리기**를 눌러 다른 이미지를 선택하고, 카메라로 바꾸려면 **카메라 시작**을 누릅니다.

### 모델

Teachable Machine 이미지 분류 모델을 사용합니다.

### 개인정보 및 데이터 처리

- 선택한 사진과 카메라 영상은 TensorFlow.js와 Teachable Machine 모델을 이용해 **사용자의 브라우저에서만** 분석됩니다.
- 사진 파일이나 카메라 영상 데이터를 별도의 서버, 업로드 API, 저장소로 보내지 않습니다.
- 모델 파일과 JavaScript 라이브러리를 불러오기 위해 인터넷 연결이 필요합니다.
- 카메라 기능은 브라우저 보안 정책에 따라 HTTPS 또는 `localhost`에서 사용해야 합니다.

### 수업 활용

학생들이 주변의 입체도형을 직접 카메라에 비추거나 사진으로 올려 보며 원기둥, 원뿔, 구의 모양을 관찰하고 서로 비교할 수 있도록 만든 초등학교 6학년 수학 6단원 학습 도구입니다.
